プライバシーポリシー

  • このアプリは、所有者本人が自分の Gmail アカウントにだけ使う個人用の接続設定です。
  • Gmail のデータは所有者の PC 上でのみ扱い、第三者に販売・提供・共有しません。
  • 認証情報(トークン)は所有者の PC 内にのみ保存します。
  • Google API から受け取ったデータの利用は、Google API Services User Data Policy(Limited Use の要件を含む)に従います。

Privacy Policy

  • This app is a personal OAuth client used only by its owner for the owner's own Gmail accounts.
  • Gmail data is processed only on the owner's own computer and is never sold, transferred or shared with third parties.
  • Credentials (tokens) are stored only on the owner's computer.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
